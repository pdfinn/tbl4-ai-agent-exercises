# tbl4-ai-agent-exercises

Supporting exercises for the Vertical Institute *GenAI Automation and Agency*
course. Each folder is a self-contained exercise you can paste straight into
Open WebUI, n8n, or any local LLM chat.

## Exercises

1. [Meeting-minutes assistant --- a two-part system prompt exercise](./01-meeting-minutes/)
   Write a plain-prose system prompt (Part 1), then restructure it with
   Markdown or XML and compare the results (Part 2).

## How to use

Each exercise has its own `README.md` with instructions, a sample input to
paste into the chat, and reference prompts you can peek at *after* you've
tried your own.
